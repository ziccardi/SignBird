# Security policy

SignBird is under active development. The project currently has no published stable release or separate supported release branch. Reports against the current development branch are welcome.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/ziccardi/SignBird/security/advisories/new) when it is available for the repository. Include the affected version or commit, the affected component, the observed impact, and enough detail to reproduce the issue with test data. Keep vulnerability details out of public issues and pull requests while the report is being investigated. Use synthetic data and omit real credentials, private keys, OTP codes, and signed documents.
